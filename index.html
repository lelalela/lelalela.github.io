엔지니어링 문제 해결 (Case Studies)

실무 트러블슈팅

특가 이벤트 시 대량 주문에 따른 재고 오버셀링 방지

도메인: 커머스 주문 및 재고

문제: 초당 1,500건의 주문이 인입될 때 DB 레벨 락(Pessimistic Lock)만으로는 커넥션 풀 고갈과 트랜잭션 타임아웃이 발생했습니다.
접근: Redisson 기반 분산 락(Distributed Lock)과 커스텀 AOP 어노테이션을 설계하여, 트랜잭션 시작 전에 락을 획득하고 트랜잭션 커밋 완료 후에 락을 해제하도록 보장했습니다.
결과: 동시 주문 2,000건 이상 상황에서도 재고 정합성 100% 유지 및 DB CPU 사용률을 35%로 안정화했습니다.

복잡한 연관관계 조회 시 JPA N+1 슬로우 쿼리 개선

도메인: 주문/배송 통합 조회 API

문제: 주문 목록 조회 시 하위 엔티티(배송지, 주문상품, 할인내역)가 지연 로딩되며 1회 요청당 350개 이상의 쿼리가 실행되어 응답 시간이 2.8초에 달했습니다.
접근: QueryDSL을 도입하여 필요한 필드만 DTO로 직접 프로젝션하고, 1:N 컬렉션 페이징을 위해 `default_batch_fetch_size`를 500으로 설정하여 IN 절 쿼리로 묶었습니다.
결과: 실행 쿼리 수 350회 → 3회로 감소, 평균 응답 속도 2.8초에서 140ms로 95% 단축되었습니다.
