Engineering Notes & Problem Solving

선착순 프로모션 환경의 동시성 제어 및 재고 오버셀링 방어

Concurrency

동일 상품에 대해 1초당 수천 건의 주문이 집중되는 환경에서 단일 RDBMS 비관적 락을 적용할 경우 DB 커넥션 풀 고갈 위험이 있었습니다. 이를 방지하기 위해 Redis Redisson 기반 분산 락을 적용하고, AOP를 통해 락 획득 시점과 스프링 트랜잭션의 커밋 시점을 정교하게 일치시켜 정합성 누수를 원천 차단했습니다.

JPA N+1 문제 해결 및 대용량 목록 조회 쿼리 최적화

Performance

다대일, 일대다 연관관계가 복잡한 주문 상세 목록에서 단일 API 호출당 300회 이상의 불필요한 서브 쿼리가 발생하는 문제를 확인했습니다. QueryDSL을 활용한 Fetch Join 재설계 및 default_batch_fetch_size 설정을 통해 쿼리 실행 횟수를 3개로 압축하고 응답 속도를 90% 이상 단축시켰습니다.
